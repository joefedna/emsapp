# Assets Directory

This directory should contain the following image assets for your Expo app:

- `icon.png` - App icon (1024x1024px recommended)
- `splash.png` - Splash screen image (1284x2778px recommended)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px recommended)
- `favicon.png` - Web favicon (48x48px or larger)

These assets are referenced in `app.json` but can be generated or added later through the Expo Dashboard or before your first EAS build.

For now, Expo will use default placeholder images if these are not provided.
